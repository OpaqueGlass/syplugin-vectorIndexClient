# Vector Retrieval Client Plugin

> A plugin that provides vector retrieval capabilities for [SiYuan Note](https://github.com/siyuan-note/siyuan) (requires use with the [server-side component](https://github.com/OpaqueGlass/simple-rag-server)).

> Under testing...  

## ✨Quick Start

- Download from the Marketplace **or**  
  1. Extract `package.zip` from the Release;  
  2. Move the folder to `workspace/data/plugins/`;  
  3. Rename the folder to `syplugin-vectorIndexClient`;
- Enable the plugin;
- Open the plugin settings and configure the server address;
- Configure a shortcut key in SiYuan settings to open the search panel;
